# Daniel-trabalho

Este projeto consiste em um portal web desenvolvido com React e TypeScript que reúne diferentes ferramentas de organização pessoal em um único sistema.

O objetivo da aplicação é oferecer ao utilizador recursos simples e eficientes para:
- gerir tarefas do dia a dia,
- cadastrar contactos,
- controlar entradas e saídas financeiras básicas.

O sistema possui navegação entre páginas, validação de formulários e persistência de dados utilizando localStorage, garantindo que as informações não sejam perdidas ao atualizar a página.

O principal valor do portal é centralizar funcionalidades úteis de organização pessoal em uma interface moderna, intuitiva e acessível.
